# Zomato Restaurant Data — Exploratory Data Analysis

## About This Project
This project is part of the Pluto Academy AI & ML Internship Program (Project 01).
I performed a complete Exploratory Data Analysis on the Zomato Restaurants dataset
from Kaggle to find patterns, trends, and business insights.

## Dataset
- Source: [Zomato Restaurants Dataset — Kaggle](https://www.kaggle.com/datasets/shrutimehta/zomato-restaurants-data)
- Rows: 9542 restaurant entries (after cleaning)
- Features: Restaurant name, location, cuisines, ratings, votes, cost, and more

## Tools Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Google Colab

## Project Structure
- `Zomato_EDA_PlutoAcademy.ipynb` — Main notebook with full analysis
- `README.md` — Project overview

## What I Did
1. Loaded and inspected the dataset (9551 rows, 21 columns)
2. Cleaned missing values, dropped irrelevant columns, fixed data types
3. Performed EDA with 5 specific questions using Pandas
4. Created 6 visualizations (bar, pie, histogram, scatter, line, heatmap)
5. Wrote 5 business insights based on findings

## Key Findings
- New Delhi dominates with 5473 restaurants — far ahead of any other city
- Only 25.69% of restaurants offer online delivery — huge growth opportunity
- North Indian cuisine is most popular with 3960 restaurants
- Higher priced restaurants consistently get better ratings
- 2148 restaurants are still unrated — affecting their visibility

## Visualizations
- Bar Chart — Top 10 cities by number of restaurants
- Pie Chart — Online delivery availability
- Histogram — Distribution of restaurant ratings
- Scatter Plot — Cost for two vs rating
- Line Chart — Average rating by price range
- Heatmap — Correlation between numeric features
